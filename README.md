# Mis Fichas APP

RESTAPI para la gestión de micro-finanzas de usuarios.

## Funcionalidades propuestas:

Registro de usuarios
Inicio de sesión
Gestión de categorías adicionales (las generales son gestionadas por el ADMIN y no son modificables)
Gestión de transacciones

## Tecnologías usadas:

- Java (17)
- Spring Boot (4.0.6)
- Spring Data JPA
- Hibernate
- Maven
- Spring Security
- MariaDB

## Consideraciones adicionales:

- Soft delete mediante `deleted_at`
- JWT (con refresh_token)
